# Langchain-LLM-Model
##Local LLaMA 3 Demo with Streamlit & LangChain

Welcome to a fun little demo that brings the power of LLaMA 3, an open-source language model, right to your local machine! This project uses Streamlit to create a simple web app where you can ask any question or type in a topic, and the app will give you a simple explanation, all powered by LangChain and hosted locally using Ollama.
